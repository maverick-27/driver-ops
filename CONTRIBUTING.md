# Contributing to Canadian Trucking Compliance Platform

We welcome contributions! This is a community-maintained corpus.

## How to Help

### 1. Update Regulations
If you find outdated regulations or have access to new ones:
1. Create a folder in `corpus/regulations/provinces/{prov}/`
2. Add the PDF or HTML file
3. Update `corpus/manifest.csv` with metadata
4. Submit a pull request

### 2. Translate Regulations (Phase 2)
We're looking for professional translators to translate key regulations into Punjabi and French. Contact us.

### 3. Fix Accuracy Issues
If an answer is wrong or misleading:
1. File an issue with the question and expected answer
2. Reference the official regulation
3. Include the doc_id and province

### 4. Improve Punjabi Support
- Test Punjabi queries
- Report issues with Gurmukhi rendering
- Suggest additional Punjabi UI labels

## Code of Conduct
Be respectful. This tool serves real truckers making important decisions.

## Questions?
Open an issue on GitHub.
